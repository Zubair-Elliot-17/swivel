# Plan

## Goal
A personal, local, improved Tangerine: same drag + modifier + wheel flow, built on system frameworks.

## Milestones
1. **Prototype the gesture:** menu-bar app that detects a file drag, shows the wheel on a modifier tap, and logs the chosen slice on drop. No conversion yet.
2. **Image conversions:** PNG / JPEG / HEIC / WebP / TIFF via ImageIO, output next to the source.
3. **PDF + OCR:** images to PDF, PDF to images, text from image (Vision).
4. **Audio / video:** AVFoundation exports (MP4, MOV, M4A, GIF).
5. **Polish:** settings, launch at login, per-type wheel layouts.

## Open questions
- Which "improvements" over Tangerine matter most (batch drops, custom presets, shortcuts)?
- Sandbox + App Store, or unsandboxed personal build?
